# Preregistration

`/qualstack:preregister` writes here. Keep this file identical to what you file with
the registry; once you paste the registry URL into `design.prereg_url`, the guard
hook makes it read-only and changes go in a dated addendum.

## Sections

1. Causal model (DAG, restrictions, confounding, priors, with the code)
2. Queries (case-level and population-level, one primary)
3. Cases (population, selection rule, the cases chosen and why)
4. Evidence plan (clues, where they will be sought, predicted probative value)
5. Coding rules (version and hash of data/coding-rules.md)
6. Updating and reporting (how posteriors will be computed and reported)
7. Decision rules (what posterior would support, undercut, or leave open each claim)
8. Robustness (pre-committed sensitivity analyses)
9. Deviations policy and data availability
